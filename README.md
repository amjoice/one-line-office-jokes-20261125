One single line that makes office life funny, written for make.fun's
"One-Line Office Jokes" bounty: https://make.fun/bounty/u-markk-st-one-line-office-jokes-a51f2bcc

The joke turns on a real detail of office life — the reply-all chain —
and lands its laugh in the last few words:

> The reply-all chain started with 'Happy birthday, Sarah' and ended with Legal replying-all to ask everyone to stop replying-all.

## Run it

```sh
python3 main.py
```

The program writes the joke to `/output/entry.txt` (one line, 128 characters,
UTF-8). Standard library only — no third-party dependencies.
